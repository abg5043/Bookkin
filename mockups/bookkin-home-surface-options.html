What is being decided

All three open on the recommendation. None opens on the shelf. The visual language is unchanged — this is information architecture only.

Copy, controls, and the underlying data are identical across options so the comparison isolates structure.

1 · The Bag

A stack is already waiting, the way a librarian hands you one. The bag persists until you act on it.

for Nothing to do on open — the value is visible immediately. Matches the physical object it describes.

against A bag you didn’t ask for can go stale, and re-generating it on every open would waste requests and make results feel arbitrary.

Open question: what triggers a new bag — time, a completed library trip, or an explicit ask?

2 · The Ask

Opens with the question, not the answer. The bag is a result you requested, and today’s context can be added in one tap.

for Matches the real rhythm — you think about this before a library trip, not continuously. Optional chips let “short tonight” or “something funny” shape a single request without becoming a permanent profile setting.

against The home screen is empty of books until you act, which is the weakest first impression of the three and the closest to a search box.

3 · Because You Loved

Anchored on a book that actually worked, with recommendations hanging off it and the reasoning visible as the organizing principle.

for Leads with the strongest signal available — a comp title beats a topic. The explanation is the structure, not a footnote, which is exactly what a library catalog cannot do.

against Needs at least one clearly-loved book, so it has a real cold-start problem. Risks feeling narrow if the anchor is stale or the child’s taste has moved.

Not represented here

  • Cold-start states, when there is not yet enough evidence for any bag.
  • The one-tap rate-and-dismiss flow, which ships with the engine.
  • Limited-pool and no-candidate results, which must never be padded.

Books shown are real titles surfaced by an actual catalog query. The reasons shown are the kind the engine will produce; none is a verified claim yet.
