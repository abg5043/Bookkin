V0.1 must do

* Support one household
* Support one child initially
* Add books using manual ISBN entry
* Add books using title search
* Scan ISBN barcodes
* Classify books as:
    * Borrowed
    * Owned
    * Discovered
    * Suggested
    * Wishlist
* Record:
    * Finished
    * Read again
    * Stopped
    * Rejected
* Record separate reactions:
    * Child: love, like, not for me
    * Parent: love, like, dislike
* Show the household’s complete book shelf
* Generate five recommendations
* Explain each recommendation
* Open a recommendation in the selected library’s catalog
* Record whether a recommendation was saved, rejected, or later scanned

V0.1 will not do

* Import library checkout history
* Log in to a library account
* Store library card numbers or PINs
* Place holds inside your application
* Claim real-time availability
* Support multiple caregivers
* Support multiple children
* Include social features
* Include reading streaks
* Include a chatbot
* Recommend books from an unlimited AI-generated universe
