# Agentic execution protocol

`CODEX_BUILD_PLAN.md` is the canonical authority. This file is a compact operating checklist, not a replacement.

## Before work

1. Read `AGENTS.md` and the complete build plan.
2. Confirm the current checkpoint and explicit approval evidence.
3. Freeze shared contracts and list included and forbidden scope.
4. Assign one writer to each shared artifact and disjoint paths to any parallel specialists.
5. Give each specialist verified fixtures, acceptance criteria, allowed commands, and authority limits.

## During work

- Do not implement later-checkpoint features.
- Do not infer permission for dependencies, services, credentials, deployment, publication, or destructive actions.
- Preserve product truth and private household boundaries.
- Stop after two bounded failures with the same cause; do not weaken tests or broaden scope.
- Specialists report files, diff scope, commands, results, provenance, limitations, and prohibited actions avoided.

## Verification and gate

1. An agent who did not implement the material work reviews it read-only.
2. The lead integrates findings and runs the complete relevant validation.
3. The lead presents the required checkpoint report and stops.
4. The human product owner inspects the work and gives guidance.
5. Requested in-scope refinements are implemented and independently reverified where affected.
6. Only explicit human approval authorizes checkpoint delivery.

Specialist completion, reviewer PASS, tests, CI, agent consensus, and lead completion do not approve a checkpoint.

## GitHub delivery after approval

- Show repository status, intended commit scope, and unrelated dirty files before approval.
- After approval, stage only the checkpoint scope, create a deliberate commit, and push the approved branch to the approved GitHub remote.
- Record commit hash, branch, remote, push result, and CI result.
- Never commit secrets, private data, unrelated work, or generated noise.
- Do not begin the next checkpoint until approval and checkpoint delivery are complete.
